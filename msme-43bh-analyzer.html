0. Staff Instructions — Exporting the Tally Ledger

Give this to whoever pulls the export — get it wrong and the FIFO matching breaks.

  1. Export the Creditors Ledger from Gateway of Tally → Display → Account Books → Group Summary/Ledger — select the "Sundry Creditors" Group of Accounts.
  2. Condensed mode will do — full voucher-level detail is not required.
  3. The export must include the running Balance column for each ledger — this is essential for FIFO matching.
  4. Include the current year's data at least till 45 days into next year (e.g. 15‑05‑2026 for a 31‑03‑2026 year-end) — this lets the tool check whether invoices were actually paid within 45 days, not just their position on the year-end date.
  5. Export as a single .xlsx file with all ledgers one after another — Tally's default multi-ledger export format. Don't split into separate files per creditor.

1. Upload Tally Ledger Export

Gateway of Tally → Display → Account Books → Ledger → select all Sundry Creditors → Export as XLSX. One sheet, multiple "Ledger:" blocks — the same format Tally produces by default.
